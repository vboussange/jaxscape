    Distance metrics¤

    jaxscape.distance.AbstractDistance ¤

    Abstract base class for distance computations on graphs.

    Provides a unified interface for computing distances with automatic handling of coordinate-based (for GridGraph) or index-based node specification.

    Arguments:

    • graph: Graph on which to compute distances.
    • sources: Source nodes as vertex indices (1D array) or coordinates (Nx2 array for GridGraph).
    • targets: Target nodes as vertex indices (1D array) or coordinates (Nx2 array for GridGraph).
    • nodes: Nodes for pairwise distances as vertex indices (1D) or coordinates (Nx2).
    • state: Optional solver setup state. Defaults to automatic initialization.

    Specify either: nodes alone, sources and/or targets, or neither (for all-pairs).

    Returns:

    Distance array with shape depending on the inputs.

    Example

    from jaxscape import LCPDistance, GridGraph
import jax.numpy as jnp

distance = LCPDistance()
permeability = jnp.ones((12, 12))
grid = GridGraph(permeability, fun=lambda x, y: (x + y) / 2)

# All-pairs distance
D = distance(grid)  # Shape: (n_nodes, n_nodes)

# Using vertex indices
D = distance(
    grid,
    sources=jnp.array([0, 1]),
    targets=jnp.array([10, 20]),
)

# Using coordinates (for GridGraph)
D = distance(
    grid,
    sources=jnp.array([[0, 0], [1, 1]]),
    targets=jnp.array([[10, 10]]),
)

# Pairwise among subset
D = distance(grid, nodes=jnp.array([0, 5, 10]))  # Shape: (3, 3)

    jaxscape.lcp_distance.LCPDistance ¤

    Compute least-cost path distances with edge cost 1/a for conductance a, using algorithm.

    For V vertices, E stored edges and S requested sources:

    • Bellman–Ford (default): Relaxes sparse edges until distances stop changing. Each round costs O(S(V + E)), with at most V − 1 rounds. Favor it for sparse graphs or a small number of sources.
    • Floyd–Warshall: Computes a dense all-pairs distance matrix by considering each vertex as an intermediate stop. Costs O(V³) time, even when requesting only selected pairs. Favor it for small dense graphs when most or all pairs are needed.

    For a unique shortest path, the derivative of its distance with respect to a is -1/a**2 on that path and zero elsewhere: increasing conductance decreases the distance. At exact ties, Bellman–Ford chooses a generalized gradient by splitting sensitivity equally among optimal incoming edges at each vertex; complete paths need not receive equal weight. Raster gradients follow by the chain rule through GridGraph.fun.

    Attributes:

    • algorithm: "bellman-ford" (default) or "floyd-warshall".

    Note

    Bellman–Ford requires positive, finite conductances; zero means no edge. Gradients assume the graph connections stay fixed. jax.jvp, jax.jacfwd, and higher-order derivatives are currently unsupported.

    Example

    from jaxscape import LCPDistance, GridGraph
import jax.numpy as jnp

grid = GridGraph(jnp.ones((5, 5)), fun=lambda x, y: (x + y) / 2)
distance = LCPDistance()
D = distance(grid, sources=jnp.array([0, 1]), targets=jnp.array([10, 20]))

    jaxscape.resistance_distance.ResistanceDistance ¤

    Compute the resistance distances.

    Attributes:

    • solver: Optional lineax.AbstractLinearSolver. Must be compatible with BCOO matrices. We currently support jaxscape.solvers.CholmodSolver, jaxscape.solvers.PyAMGSolver, jaxscape.solvers.AMJaxCGSolver, and jaxscape.solvers.CuDSSSolver. If None, uses the pseudo-inverse method, which is very memory intensive for exact all-pairs distances (densifies the Laplacian matrix), or dense solves for approximate distances.
    • method: A resistance distance method. Defaults to ExactResistance(). Use SpielmanApproximation(epsilon=..., seed=...) for the randomized Spielman-Srivastava approximation.

    Example

    import jax.numpy as jnp
from jaxscape import GridGraph, ResistanceDistance, SpielmanApproximation
from jaxscape.solvers import AMJaxCGSolver, PyAMGSolver

permeability = jnp.ones((3, 3))
grid = GridGraph(permeability, fun=lambda x, y: (x + y) / 2)

# Default: pseudo-inverse (small graphs)
distance = ResistanceDistance()

# With solver (large graphs)
distance = ResistanceDistance(solver=PyAMGSolver())

# With an initialized AMG-preconditioned CG solver
distance = ResistanceDistance(
    solver=AMJaxCGSolver(rtol=1e-6, atol=1e-6, max_steps=1_000)
)
state = distance.init(grid)

dist = distance(grid, state=state)

# Carry a state from one graph to the next, as an optimization loop does.
# AMJax keeps its hierarchy.
updated_permeability = permeability * 1.1
updated_grid = GridGraph(updated_permeability, fun=lambda x, y: (x + y) / 2)
state = distance.reinit(updated_grid, state)
dist = distance(updated_grid, state=state)

# Approximate resistance distance
distance = ResistanceDistance(
    method=SpielmanApproximation(epsilon=0.05),
    solver=PyAMGSolver(),
)

dist = distance(grid)

    Warning

    The graph must be undirected for resistance distance to be well-defined.

    jaxscape.resistance_distance.SpielmanApproximation ¤

    Spielman-Srivastava randomized resistance distance approximation.

    Attributes:

    • epsilon: Accuracy parameter. Smaller values use more random projections: ceil(log(n_vertices) / epsilon**2), which increases memory use.
    • seed: Random seed for the Rademacher edge projections.
    • projection_batch_size: Number of projection rows evaluated together. Larger batches can improve throughput at the cost of more working memory; choose a size that fits your device.

    Removed in 0.0.14

    RSPDistance is removed. FreeEnergyDistance replaces it, with edge costs equal to inverse conductances and symmetric first-hitting free energies as output. Its values differ from the expected path costs that RSPDistance returned.

    jaxscape.free_energy_distance.FreeEnergyDistance ¤

    Symmetric first-hitting free-energy distance with edge costs \(1/a_{ij}\).

    Attributes:

    • theta: Finite positive scalar inverse temperature. Larger values concentrate the path distribution on least-cost paths. Distances are differentiable with respect to theta.
    • solver: Optional Lineax solver, with the same options as ResistanceDistance. None uses a dense solve, suitable for small graphs.

    For conductances \(a_{ij}\), let \(c_{ij}=1/a_{ij}\) on present edges, \(P_{ij}=a_{ij}/\sum_k a_{ik}\), and \(Z=(I-P\odot e^{-\theta C})^{-1}\). The first-hitting partition is \(z^h_{ij}=Z_{ij}/Z_{jj}\) and \(d_{ij}=-(\log z^h_{ij}+\log z^h_{ji})/(2\theta)\). For the derivation, see Kivimäki, Shimbo & Saerens and Françoisse et al..

    The graph must be connected and symmetric, with positive finite conductances on present edges. Conductance enters both the edge costs and the transition probabilities. As theta grows, the distance approaches the least-cost distance with edge costs \(c_{ij}\). On a graph without self-loops and with m undirected edges, the small-theta limit is m times the effective resistance. Solver state depends on the conductances and on theta; pass it through reinit when either changes.

    Precision and errors: float32 and float64 inputs are supported. Entries of \(Z\) decay exponentially with path cost, and float64 resolves smaller entries, hence larger distances and larger theta. Each queried logarithm is checked against a residual-based error estimate; unresolved entries raise an EquinoxRuntimeError and are never clipped or substituted. The estimate includes heuristic rounding allowances, so accuracy should be validated for the intended workload. Checks use eqx.error_if; on GPU, a failed check may be reported without raising, depending on EQX_ON_ERROR.

    Differentiation: first-order reverse mode reuses the forward solutions. Forward-mode and higher-order derivatives are not validated.

    Example

    import jax.numpy as jnp
from jaxscape import FreeEnergyDistance, GridGraph

raster = jnp.array([[0.8, 1.2], [1.4, 0.9]])
grid = GridGraph(raster, fun=lambda x, y: (x + y) / 2)
distances = FreeEnergyDistance(theta=0.5)(grid, nodes=jnp.array([0, 3]))
